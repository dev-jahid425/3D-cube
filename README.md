# 🎲 Animated 3D Cube

A simple and visually appealing **3D rotating cube animation** built using pure **HTML** and **CSS**. This project demonstrates the power of CSS transforms, perspective, and keyframe animations to create a smooth 3D effect without using JavaScript or external libraries.

## ✨ Features

- 🧊 Fully animated 3D cube
- 🎨 Built with only HTML and CSS
- ⚡ Lightweight and fast
- 📱 Responsive design
- 🚀 Beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
  - CSS Transforms
  - CSS Perspective
  - CSS Animations (@keyframes)
